📖 Tentang Plugin

ASMAK Command Center adalah plugin WordPress yang powerful untuk integrasi dengan berbagai layanan API eksternal. Plugin ini menyediakan solusi lengkap untuk mengelola dan mengintegrasikan berbagai layanan dalam satu dashboard terpusat.

🛠️ Instalasi

  1. Download plugin dari link di bawah
  2. Upload folder plugin ke direktori /wp-content/plugins/
  3. Aktifkan plugin melalui menu 'Plugins' di WordPress
  4. Konfigurasi API keys di menu Settings > ASMAK Command Center

💻 Setup Auto-Update di Plugin WordPress

Tambahkan kode berikut ke file plugin utama Anda:

// File: asmak-command-center.php

// Setup auto-update checker
require_once plugin_dir_path(__FILE__) . 'includes/updater.php';

if (is_admin()) {
    $updater = new ASMAK_Plugin_Updater(__FILE__);
    $updater->set_update_url('https://adsguru22.github.io/asmak-updates/info.json');
    $updater->initialize();
}
