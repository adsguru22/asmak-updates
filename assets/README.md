# Assets Directory

This directory contains visual assets for the ASMAK Command Center plugin.

## Required Assets

For a complete WordPress plugin listing, you should include:

### Banners
- `banner-772x250.png` - Low resolution banner (772x250 pixels)
- `banner-1544x500.png` - High resolution banner (1544x500 pixels)

### Icons
- `icon-128x128.png` - 1x icon (128x128 pixels)
- `icon-256x256.png` - 2x icon (256x256 pixels)

## Design Guidelines

### Banner Design
- Use your brand colors
- Include plugin name
- Keep it professional and clean
- Ensure text is readable at both resolutions

### Icon Design
- Simple and recognizable
- Works well at small sizes
- Use transparent background (PNG)
- Consider using your logo or a symbolic representation

## Adding Your Assets

1. Create your banner and icon files following the dimensions above
2. Place them in this directory
3. Update the URLs in `info.json` if you're hosting them elsewhere
