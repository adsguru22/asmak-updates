## 🚀 How It Works

### Update Flow
1. Developer creates GitHub Release with plugin ZIP
2. GitHub Actions workflow triggers automatically
3. `info.json` updated with new version and download URL
4. Changes deployed to GitHub Pages
5. WordPress sites check for updates (12-hour cache)
6. Users get update notification in WP admin
7. One-click update downloads from GitHub Release

### Technical Implementation
- Update server: GitHub Pages (free hosting)
- Automation: GitHub Actions workflow
- WordPress integration: Custom updater class
- Caching: 12-hour transient cache
- Security: HTTPS-only, WordPress sanitization
